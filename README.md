# Claude Code CLI 中英文对照说明书

> 一份完整的 Claude Code 命令行工具中英文对照参考手册

## 在线预览

本地启动：

```bash
cd claude-code-ref
python3 -m http.server 12341
```

打开 `http://localhost:12341` 即可查看。
